# 🎬 Video Production Dashboard

Welcome to the AI Video Production command center!
This page uses the **Dataview** plugin to automatically organize outputs generated by your Editing Workspace.

*(Note: You must have the [Dataview Plugin](https://github.com/blacksmithgu/obsidian-dataview) installed and enabled in Obsidian to see these tables).*

---

## 🚧 Active Projects

These are projects currently in the `planning` stage.

```dataview
TABLE 
  created_date AS "Started",
  title AS "Project Name",
  "[[takes_packed|Transcript]]" AS "Raw Transcript"
FROM "Video Projects"
WHERE type = "video_project" AND status = "planning"
SORT created_date DESC
```

---

## ✅ Completed Projects

Videos with finalized edits and exported assets.

```dataview
TABLE 
  created_date AS "Started",
  title AS "Project Name",
  "[[description|Description]]" AS "Description",
  "[[timestamps|Chapters]]" AS "Chapters"
FROM "Video Projects"
WHERE type = "video_project" AND status = "completed"
SORT created_date DESC
```

---

## 📝 Latest Generated Captions & Titles

Quick reference for social posts generated by the AI agent.

```dataview
TABLE 
  type AS "Asset",
  platform AS "Platform",
  date AS "Generated On"
FROM "Video Projects"
WHERE type = "social_post" OR type = "video_titles"
SORT date DESC
LIMIT 10
```

---

## 📘 How this works
Whenever your AI agent runs `./scripts/new-project.sh` inside the workspace (with Obsidian mode enabled), it drops a `project.md` file filled with YAML properties (like `type: video_project` and `status: planning`). Then, as the agent auto-generates your descriptions, captions, and thumbnails, those new files pop up in the vault and instantly link here.
